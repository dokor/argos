# Social sign-in brand assets

These assets are served locally; no third-party image request is made when the form loads.

- GitHub black/white Invertocat SVGs: https://brand.github.com/foundations/logo — https://brand.github.com/GitHub_Logos.zip
- LinkedIn `LI-In-Bug.png`: https://brand.linkedin.com/downloads — https://content.linkedin.com/content/dam/me/business/en-us/amp/xbu/linkedin-revised-brand-guidelines/logos/in-logo.zip
- Google light icon PNG (Android + Web, square, no text, @4x): https://developers.google.com/identity/branding-guidelines — https://developers.google.com/static/identity/images/signin-assets.zip

The original PNGs are copied unchanged from the official downloads. The Google SVG wrapper embeds the PNG locally and clips to the official SVG mark path to remove the button frame, preserving its gradient. LinkedIn uses a blue square SVG mark with white lettering and no surrounding white gutter. No CSS color filters are applied. Provider trademarks belong to their respective owners. Google is displayed at the supplied 20px mark size; the surrounding button frame is excluded by the SVG clip. GitHub uses its supplied black/white variant according to the Argos theme.
